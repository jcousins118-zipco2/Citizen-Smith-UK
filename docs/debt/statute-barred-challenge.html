Statute-Barred Challenge

Use when: you are being chased for an old debt that may be beyond the limitation period.

The likely position

You may be able to challenge collection activity if the debt is statute-barred and there has been no payment or written acknowledgement within the relevant period.

What to keep

  • the date of the last payment, if known
  • the date of the last written acknowledgement, if any
  • collection letters or emails

Template wording

If they keep going

Formal complaint first, then Financial Ombudsman Service if a regulated firm continues unfair collection activity.
