Request for Written Communication Where Possible

Use when: phone calls are making things worse and you need a clearer record you can manage confidently.

Likely rule

FCA fair treatment, vulnerability, and proportionate communications principles.

What to keep

  • any prior request for written contact
  • call logs after the request
  • any written refusal or failure to comply

Template wording

Next escalation

Oppressive contact complaint, vulnerability complaint, then FOS if the conduct continues.
