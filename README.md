# Citizen Smith

Citizen Smith is a static, source-led UK legal-information website for people who need a practical next step in plain English.

## Site flow

The home page lets a visitor choose one of six areas—debt and credit, housing, energy, telecoms and internet, benefits, or employment—then choose an issue and view guidance generated by the site’s JavaScript.

## Content

- Topic guidance lives under `docs/` for benefits, debt, employment, energy, housing, and telecoms.
- Reusable pages cover how the site works, sources, about information, and the disclaimer.
- `registry/` contains source and template indexes.
- `assets/` contains the shared stylesheet and client-side logic.

The site is plain HTML, CSS, and JavaScript; the repository has no package manifest or build configuration.

## Important limits

The site states that it provides general information and document support, not legal advice or representation. Visitors should check the disclaimer and sources pages and seek specialist help where appropriate.
