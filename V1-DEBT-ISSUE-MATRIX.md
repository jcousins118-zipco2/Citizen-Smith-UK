# Citizen Smith — V1 Debt Issue Matrix

## Purpose
This matrix is the operating backbone for V1 debt & credit.
It connects each user problem to:
- the likely rule
- the source hierarchy
- the document/template type
- the next escalation path

This prevents the site becoming a pile of disconnected letters.

---

## 1. Two parties chasing the same debt

**User problem**
- A bank and a debt collector are both emailing, calling, or writing about the same account
- The user does not know who is actually in control
- The user risks paying the wrong party or getting contradictory demands

**Likely rule / position**
- FCA CONC 7.13.10
- fair treatment / proportionate contact principles
- complaint handling expectations where confusion is being caused

**Primary sources**
- FCA Handbook (CONC 7)
- FOS complaint process pages

**Trusted support sources**
- National Debtline
- Citizens Advice
- StepChange

**Document types**
- quick send: dual-contact challenge
- formal complaint: contradictory creditor / collector complaint
- case-building: control-of-debt evidence log

**Core document purpose**
- force the firms to state who owns or controls the debt
- force one named contact
- stop overlapping approaches

**Escalation path**
- internal complaint
- FOS if unresolved or harmful conduct continues

**Evidence to gather**
- copies of messages from both parties
- dates and times of contact
- conflicting payment instructions
- reference numbers from both organisations

## Operating Rule

For every issue in V1 debt, Citizen Smith should answer five things fast:
1. what is happening?
2. which rule may apply?
3. what should the user send now?
4. what evidence should they keep?
5. where do they escalate next?
